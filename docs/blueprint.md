# **App Name**: Memory Lane

## Core Features:

- Card Display: Display a grid of face-down cards.
- Match Logic: Handle card selection and matching logic.
- Reset Game: Game reset functionality.

## Style Guidelines:

- Background color: Soft beige (#F5F5DC) for a calm feel.
- Card color: Light blue (#ADD8E6).
- Accent: Teal (#008080) for interactive elements.
- Clean, centered layout for the card grid.
- Subtle card flipping animation.
- Simple, recognizable icons for card matching.
